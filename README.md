# HEG Radio – kostenlose Restaurantdaten Deutschland

Öffentliche, regelmäßig aktualisierte SQLite-Datenbank aus © OpenStreetMap-Mitwirkende, ODbL 1.0. Quelldownloads: Geofabrik. Nur Geschäftsdaten aus öffentlichen OSM-Einträgen. Telefonnummern und Öffnungszeiten können unvollständig/veraltet sein.

Der GitHub-Actions-Workflow wird sonntags automatisch ausgeführt (03:17 UTC), außerdem manuell unter **Actions → HEG Radio Restaurantdaten Deutschland → Run workflow**. Ein erfolgreicher Lauf ersetzt die Release-Datei `heg_food_osm.sqlite.gz` und `info.json`. Kein eigener Rechner erforderlich. Workflow-Läufe können wegen GitHub-Limits, Downloadfehlern oder Datenänderungen scheitern; Status unter Actions prüfen. Keine Echtzeit-Garantie.

Download: `https://github.com/funjocke4/HEG-Radio-Food-Data/releases/download/food-live/heg_food_osm.sqlite.gz`

Bitte bei externer Weitergabe die ODbL-Attributionspflichten prüfen und die Quelle in der Android-App sichtbar nennen. Die App lädt eine vollständige, komprimierte Deutschland-Datenbank und nicht nur regionale Delta-Änderungen.
